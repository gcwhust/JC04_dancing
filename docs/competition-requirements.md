# 机器人舞蹈赛道要求与交付检查

依据《模拟仿真赛道任务说明书》的机器人舞蹈部分整理。下表区分任务书要求与项目选择的实现方式；独立评分细则未提供，因此不评估具体分值。

当前提交示例采用 `new_year`：自由浮动机身、双驱动轮锁止、0.0005 秒物理步长、浅色棋盘地面。完整视频已加入配乐，设计说明为两页，内容包括小楚机器人、仿真平台与模型、运行流程。项目另提供 `doudoulong` 的85秒完整无声录像；当前 `report` 和 `submit` 仅支持 `new_year`，下表的交付检查针对新年示例。

## 文件与复现

按 [README](../README.md) 执行 `record → add-audio → report → submit`，生成
`submission/ROBOT261937J_机器人舞蹈/` 及同级提交材料 ZIP。内层目录包含命名视频、
设计说明、流程图、源码 ZIP、运行记录与截图、`manifest.json`、`SHA256SUMS`。
源码和外层 ZIP 的组织方式是便于复现的项目约定。

视频采用 1920×1080、30 FPS、H.264/AAC，配乐从第 2 秒开始。声轨合成保持视频
画面与物理运行不变。已完成普通安装后的独立仿真与录像复现；详细结果见
[验证记录](validation.md)。任何后续剪辑或换曲都应重新核验成片与材料中的对应信息。

模型和动作资产随安装包提供。仿真采用轮子角位置制动的软约束，机身仍自由浮动，
不把轮子锁止等同于世界坐标完全冻结；接触及关节限位近似见
[模型说明](model-conversion.md)。音乐身份、权利与同步状态见
[配乐说明](audio-provenance.md)。

Ubuntu 22.04、Conda、1080p/30 FPS 及源码 ZIP 干净安装重录为项目选择的复现标准。
灵巧手赛道的物体类别、抓取成功率、5 分钟视频上限等不作为本项目要求。
