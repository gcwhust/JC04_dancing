# 机器人舞蹈赛道要求与交付

依据《模拟仿真赛道任务说明书》的机器人舞蹈部分整理。独立评分细则未提供，不评估具体分值。当前作品使用新编排的《天鹅湖》动作，以下为实现与交付对应。

| 要求 | 当前实现 |
|---|---|
| 仿真完成舞蹈设计与编程 | MuJoCo 自由浮动机身，双臂、双腿、双主轮协同控制 |
| 舞蹈 20–120 秒 | 主体 94 秒，含准备、回位及保持共 99 秒 |
| 至少三种不同动作，多关节协调 | 展翼、屈膝起伏、前后滑行、左右应答、差速缓转和谢幕 |
| 动作与音乐节奏或旋律配合 | 按《天鹅湖》节选的音乐结构重新编排；时间点依据波形与频谱选取，未进行人工试听评价 |
| 原创编排 | 由本项目参数化生成器重新编排，生成器、CSV 与段落时间表随附 |
| README 注明平台具体版本 | MuJoCo 3.3.7、Python 3.10.22，环境及依赖锁定文件随附 |
| 模型与说明、来源及版本 | JC04 desc4 V1.3、URDF/MJCF、网格、转换说明与来源清单随附 |
| 完整视频、源码、设计说明 | 有声 MP4、可运行源码 ZIP、简洁中文设计 PDF |
| 规定命名的 MP4/PDF | `ROBOT261937J_机器人舞蹈_视频.mp4`、`ROBOT261937J_机器人舞蹈_文档.pdf` |
| 流程图 | 文档内含六步流程图，并输出独立 PNG/PDF |

按 [README](../README.md) 执行 `record → add-audio → report → submit`。生成目录包含命名视频、设计说明、流程图、源码 ZIP、运行记录和截图、manifest.json 与 SHA256SUMS，另有外层材料 ZIP。

视频采用 1920 × 1080、30 FPS、H.264/AAC。前 2 秒准备，随后 94 秒配乐与舞蹈主体共用同一时间轴。合成保留视频像素并解码检查声音；最终运行结果见[验证记录](validation.md)。仿真通过不代表比赛主观评分或真机验证。
