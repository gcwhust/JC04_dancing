## 单舞蹈清理复验

仓库仅注册和提供《天鹅湖》的动作与配乐。播放器仅接受显式 `time_s`、10 个臂腿角度和 2 个轮速通道，已移除六关节动作、帧号时钟、三次插值和自动腿部摆动的兼容路径及参数。

清理前后按 0.0005 秒步长比对完整时间轴的 198001 组关节与轮速目标，浮点数据逐字节一致；随后从清理后的源码和配置重新完成 99 秒录制、配乐合成与报告打包。上表物理统计与清理前一致，动作 CSV 和音乐未改变。源码包包含本次 README 和运行代码。
